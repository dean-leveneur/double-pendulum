# Pendule Double

Projet étudiant (INSA Lyon) de modélisation numérique.
Ce projet simule le comportement chaotique d'un pendule double en résolvant numériquement les équations du mouvement.

**Lancement :**
Ouvrir et exécuter le notebook `double_pendulum.ipynb` (nécessite `numpy`, `scipy` et `matplotlib`).
